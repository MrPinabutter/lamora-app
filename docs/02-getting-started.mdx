# Getting Started

Guide to get the project running locally.

## Prerequisites

- **Node.js** 20 or higher
- **pnpm** (the project's package manager)
- **Docker** — used to bring up the local PostgreSQL

## 1. Install dependencies

```bash
pnpm install
```

## 2. Environment variables

Copy the example file and adjust it if needed:

```bash
cp .env.example .env
```

## 3. Bring up the database

PostgreSQL runs in a Docker container (port **5433** on the host):

```bash
docker compose up -d db
```

Then apply the migrations and generate the Prisma Client:

```bash
pnpm db:migrate
```

## 4. Run the project

```bash
pnpm dev          # application at http://localhost:3000
pnpm storybook    # Storybook at http://localhost:6006
```
