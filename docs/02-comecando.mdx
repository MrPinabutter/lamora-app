# Começando

Guia para colocar o projeto rodando localmente.

## Pré-requisitos

- **Node.js** 20 ou superior
- **pnpm** (gerenciador de pacotes do projeto)
- **Docker** — usado para subir o PostgreSQL local

## 1. Instalar dependências

```bash
pnpm install
```

## 2. Variáveis de ambiente

Copie o arquivo de exemplo e ajuste se necessário:

```bash
cp .env.example .env
```

## 3. Subir o banco de dados

O PostgreSQL roda em um container Docker (porta **5433** no host):

```bash
docker compose up -d db
```

Em seguida, aplique as migrations e gere o Prisma Client:

```bash
pnpm db:migrate
```

## 4. Rodar o projeto

```bash
pnpm dev          # aplicação em http://localhost:3000
pnpm storybook    # Storybook em http://localhost:6006
```
