# Design Tokens

A identidade visual da Lamora é **minimalista**: neutros quentes, muito espaço
em branco e um único acento dourado. Os tokens são definidos em CSS, via
`@theme`, no arquivo `src/app/globals.css`.

## Como usar

Os tokens viram utilitários do Tailwind automaticamente. Use as classes em vez
de valores fixos:

```tsx
<div className="bg-surface text-foreground border-border border">
  <h2 className="text-foreground font-serif">Título</h2>
  <p className="text-muted">Descrição secundária.</p>
  <button className="bg-primary text-primary-foreground">Comprar</button>
</div>
```

Para classes condicionais, sempre use o utilitário `cn()` de
`shared/lib/utils.ts` — nunca concatene strings de classe na mão.
