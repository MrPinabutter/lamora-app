# Design Tokens

Lamora's visual identity is **minimalist**: warm neutrals, plenty of white
space and a single golden accent. The tokens are defined in CSS, via `@theme`,
in the `src/app/globals.css` file.

## Usage

The tokens automatically become Tailwind utilities. Use the classes instead of
hard-coded values:

```tsx
<div className="bg-surface text-foreground border-border border">
  <h2 className="text-foreground font-serif">Title</h2>
  <p className="text-muted">Secondary description.</p>
  <button className="bg-primary text-primary-foreground">Buy</button>
</div>
```

For conditional class merging during composition, use the `cn()` utility from
`shared/lib/utils.ts` — never concatenate class strings by hand.

## Component variants with `tailwind-variants`

The primitives in `shared/components/ui/` do **not** assemble `className` by
hand nor stack `cn()` calls. Each component's styling is declared with
[`tailwind-variants`](https://www.tailwind-variants.org/) (`tv`), which gathers
in one place the base classes, the variations (`variant`, `size`, …) and their
defaults.

```tsx
import type { ButtonHTMLAttributes } from "react";
import { tv, type VariantProps } from "tailwind-variants";

const button = tv({
  base: "inline-flex items-center justify-center rounded-full font-medium",
  variants: {
    variant: {
      primary: "bg-primary text-primary-foreground hover:bg-primary/90",
      ghost: "text-foreground hover:bg-foreground/5",
    },
    size: { sm: "h-9 px-3 text-sm", md: "h-11 px-5 text-sm" },
  },
  defaultVariants: { variant: "primary", size: "md" },
});

// The variant props come from tv itself — no duplicated type union.
type ButtonProps = ButtonHTMLAttributes<HTMLButtonElement> &
  VariantProps<typeof button>;

export function Button({ variant, size, className, ...props }: ButtonProps) {
  // Base + variant + the consumer's className, conflicts already resolved.
  return <button className={button({ variant, size, className })} {...props} />;
}
```

Rules:

1. **One `tv()` definition per component**, right after the imports. Components
   without variations also use `tv()` — with just `base` — to keep the pattern.
2. **The types come from `tv`.** Derive the variant props with
   `VariantProps<typeof …>`; never re-declare the variant union by hand.
3. **Multiple styled nodes? Use `slots`.** Components with more than one styled
   element (such as `Modal` and `Drawer`) declare one slot per node, instead of
   several loose `tv()` definitions.
4. **`tv()` for the component, `cn()` for the rest.** `tv()` defines the
   styling API of a primitive; `cn()` remains the tool for one-off conditional
   merging when composing features.

`tailwind-variants` resolves class conflicts internally (via `tailwind-merge`),
so passing `className` in the call — `button({ className })` — overrides the
base safely.
