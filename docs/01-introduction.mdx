# Lamora

**Lamora** is a perfumery e-commerce — perfumes, moisturizers, exfoliants and
skin care — with a minimalist curation. This documentation gathers everything
you need to understand, run and contribute to the project.

## What's in the MVP

The first release focuses on the essentials to validate the business:

- **Landing page** — brand identity, best sellers, partner brands and
  testimonials.
- **Catalog** — listing with filters (category, brand, price range), sorting
  and a product detail page with the olfactory pyramid.
- **Cart** — off-canvas sidebar with checkout via **WhatsApp** (no payment
  checkout in the MVP).
- **User accounts** — sign-up with LGPD consent, login, profile and account
  deletion with anonymization.
- **Admin panel** — product CRUD, user management and a dashboard of conversion
  metrics.

> Integrated payment, reviews and wishlist are deferred to **v2** — the
> feature-first structure already accommodates those domains without a rewrite.

## How to navigate this documentation

- **Getting Started** — install dependencies, bring up the database and run the
  project.
- **Architecture** — the feature-first principles and the folder organization.
- **Design Tokens** — the brand palette and typography.
- **Components** — the rules for writing clean components and their stories.

The generic UI components are cataloged in the **Atoms**, **Molecules** and
**Organisms** sections of the sidebar, each one with interactive examples.
